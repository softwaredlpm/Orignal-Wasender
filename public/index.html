How to Configure in BUSY 21 / 18

Step-by-step setup in under 2 minutes
1
Open WhatsApp Configuration
In BUSY, click Administration → Configuration → WhatsApp / SMS Configuration.
2
Add or Edit Format
Click Add New Format, enter name as WhatsApp, and check Send PDF link for Invoice.
3
Paste the API URL & Parameters
Select Service Provider Server. Copy and paste the WhatsApp API URL into the box. Then in the table, set parameter names to Mobile and Message.
4
Configure Number Treatment & Save
Select Truncate with Prefix with Length 10 and Prefix 91. Click Save. You are now ready to send WhatsApp invoices directly from BUSY!
